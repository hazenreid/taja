# taja

자판을 처음 배우는 사람을 위한 터미널 타자 연습기입니다 (Rust).

홈열 키 몇 개로 시작해서, 열린 키가 **모두** 목표 속도와 정확도를 넘으면 다음 키가 하나씩 열립니다.
연습 문장은 열린 키로만 만들어지고, 모든 단어에 가장 약한 키(집중 키)가 들어갑니다.

## 실행

```sh
cargo run --release                     # QWERTY
cargo run --release -- --layout mine    # 직접 만든 레이아웃
cargo run --release -- --lang ko        # 한글 (두벌식)
cargo run --release -- --help           # 옵션 보기
```

| 키 | 동작 |
|---|---|
| 글자 | 입력 (틀리면 맞는 키를 칠 때까지 커서가 멈춤) |
| `Tab` | 새 줄 |
| `Esc` / `Ctrl+C` | 저장하고 종료 |

화면 글자, 알림, 오류 메시지, `--help`는 영어로 표시됩니다.

옵션:

- `--lang en|ko`: 연습할 언어 (기본 en)
- `--target-wpm 30`: 키별 목표 속도 (기본 30, 한글은 ×5 해서 150 KPM으로 표시)
- `--target-acc 95`: 키별 목표 정확도 % (기본 95)
- `--reset`: 이 레이아웃의 진도를 지우고 처음부터
- `--paths`: 레이아웃 폴더와 진도 폴더 위치 보기
- `--dict <경로>`: 영어 단어를 가져올 사전 파일 (기본 `/usr/share/dict/words`)
- `--corpus <경로>`: 영어 언락 순서에 쓸 `corpus.bin` (기본: 저장소의 `assets/corpus.bin`)

## 레이아웃 파일

10×3 글자만 적으면 됩니다. 공백은 무시하고, **영어 글자(a~z)가 아닌 칸은 모두 빈 칸**(키 없음)입니다.
빈 칸은 `.`, `;`, `-` 등 아무 기호로 적으면 됩니다. 내장 QWERTY의 `; , . /` 자리도 빈 칸입니다.

```
qwertyuiop
asdfghjkl;
zxcvbnm,./
```

`taja --paths`로 나오는 레이아웃 폴더(Linux: `~/.config/taja/layouts/`)에 `mine.txt`로 저장하고
`--layout mine`으로 실행합니다. 파일 경로를 바로 줘도 됩니다 (`--layout ./mine.txt`).

저장소에 있는 예시: `layouts/mine.txt`

```
pmal.zbfjy
inerqxot.s
kvgd..hcuw
```

```sh
cargo run --release -- --layout layouts/mine.txt
```

이 배열의 계산 결과 (assets/corpus.bin 기준): 시작 키 `t i n o` (4개) → `e r s a h d c l f m g u p b w v y k j x q z`
레이아웃은 OS나 키보드 펌웨어에 설치된 상태여야 합니다. 프로그램은 들어온 글자를 그대로 비교합니다.

나머지는 모두 위치로 자동 계산합니다:

- **손가락**: 열 번호로 정함 (0 왼손 새끼 … 3·4 왼손 검지 | 5·6 오른손 검지 … 9 오른손 새끼)
- **시작 키 (4~8개 자동, 빈도 기준)**: 홈열 8칸(안쪽 두 칸 제외)의 키 중에서, 그 키들(과 공백)로 칠 수 있는
  트라이그램 빈도가 **가장 높은 조합**을 고름. 4개부터 늘려 가며, 사전 단어가 10개 이상 나오는 조합이 있는
  가장 적은 개수에서 멈춤. 손가락 위치는 따지지 않음 (빈도로 최적화한 레이아웃이면 흔한 글자가 이미 편한 자리에 있음).
  8개로도 부족하고 모음이 없으면 가장 쉬운 자리의 모음을 하나 추가
  - QWERTY: `a s l d` (4개)
  - `layouts/mine.txt`: `t i n o` (4개)
- **언락 순서 (트라이그램)**: 남은 키마다 "이 키를 열면 이미 열린 키(와 공백)와 함께 새로 칠 수 있게 되는
  트라이그램(세 글자 연속)의 빈도 합"을 구하고, 글자 빈도를 조금 더한 뒤 자리 비용으로 나눠 가장 큰 키부터 엶
  - **롤**(세 글자가 같은 손, 서로 다른 손가락, 한 방향으로 이어짐)인 트라이그램은 1.5배로 쳐줌.
    롤링 레이아웃이면 자주 쓰는 롤 동작이 일찍 열림
  - 영어: `corpus.bin`의 트라이그램 빈도. 파일이 없으면 사전 단어로 센 값으로 대신함 (빈도 정보가 없어 덜 정확)
  - 한글: 내장 단어 목록의 빈도로 두벌식 키 트라이그램을 셈
  - 언락 순서는 진도를 처음 만들 때 계산함. `corpus.bin`을 바꾼 뒤에는 `--reset`으로 새로 시작해야 반영됨
  - 결과 예 (시작 키는 맥 웹스터 사전, 순서는 저장소의 `assets/corpus.bin` 기준):
    - QWERTY: `asld` → `e r i t h n o f c m g u w p v k b y j x q z`
    - `layouts/mine.txt`: `tino` → `e r s a h d c l f m g u p b w v y k j x q z`

### corpus.bin 위치

저장소의 **`assets/corpus.bin`**에 두면 됩니다. 빌드할 때 저장소 경로를 기억하므로 어느 폴더에서 실행해도 찾고,
실행할 때마다 읽으므로 파일을 바꿔도 다시 빌드할 필요가 없습니다 (단, 언락 순서는 `--reset` 해야 새로 계산됨).
다른 파일은 `--corpus <경로>`로 지정합니다.

### corpus.bin 형식

`CorpusStats { letters, bigrams, trigrams }`를 bincode 1 기본 설정(리틀엔디언, 고정 길이 정수)으로 직렬화한 파일.
헤더 없이 맵 세 개가 차례로 들어 있습니다. 글자는 UTF-8, 횟수는 u64입니다.

```
[u64 개수] + (char, u64) × 개수               ← letters
[u64 개수] + (char, char, u64) × 개수         ← bigrams (지금은 안 씀)
[u64 개수] + (char, char, char, u64) × 개수   ← trigrams
```

영어 글자는 소문자로 바꾸고, 영어 글자와 공백이 아닌 글자가 든 항목은 버립니다.

진도는 레이아웃마다 따로 저장됩니다 (Linux: `~/.local/share/taja/profiles/<이름>.json`).
레이아웃 파일 내용이 바뀌면 진도를 새로 시작합니다.

## 언락 기준

- 키마다 최근 30번의 입력으로 평가
- **속도**: 바로 앞 키를 친 뒤 이 키를 칠 때까지 걸린 시간의 평균 (2초 넘게 쉰 입력은 제외)
- **정확도**: 한 번에 맞게 친 비율
- 열린 키가 모두 20번 이상 입력되고, 목표 속도와 목표 정확도를 넘으면 다음 키가 열림

## 집중 키

연습 줄의 모든 단어에 들어가는 키입니다. 열린 키 중에서 이 순서로 고릅니다.

1. 아직 20번을 못 친 키 (새로 열린 키)
2. **정확도가 가장 낮은 키**
3. 정확도가 같으면 속도가 느린 키, 그것도 같으면 나중에 열린 키

## 연습 문장

- **영어 단어는 사전 파일에서만 가져옴**: 실행할 때 `/usr/share/dict/words`(맥은 웹스터 사전 약 23만 개)를 읽음
  - 모든 단어를 소문자로 바꿔서 씀 (`Paris` → `paris`). 영어 글자로만 된 2~10글자 단어, 거르는 단어 없음
  - 다른 파일은 `--dict <경로>` (한 줄에 한 단어). 파일이 없으면 오류로 알려줌
  - 사전에 빈도 정보가 없어서 흔한 단어와 희귀어가 같은 비율로 나옴
- **진짜 단어 우선**: 집중 키가 든 진짜 단어가 15개 이상이면 진짜 단어만 씀
  - 그보다 적으면 진짜 단어를 한 줄에 각 2번까지 먼저 쓰고, 남는 자리만 가짜 단어로 채움
  - 가짜 단어는 영어 글자 연결 빈도로 만듦 (예: `flads`, `kalds`). 집중 키가 든 진짜 단어가 아예 없을 때 주로 나옴
- **틀린 단어 복습**: 한 줄을 끝낼 때 틀린 키가 있었던 단어를 기억해 두었다가 다음 줄들에 다시 넣음
  - 사전에 있는 진짜 단어만 기억함 (가짜 단어는 안 넣음)
  - **지금 집중 키가 들어간 단어일 때만** 다시 나옴. 집중 키가 바뀌면 그 키가 든 틀린 단어만 나옴
  - 다시 나왔을 때 한 번에 맞게 치면 목록에서 빠짐. 최대 100개까지, 진도 파일에 같이 저장
- **모든 단어에 집중 키가 들어감** (진짜 단어는 집중 키가 든 것만 고르고, 가짜 단어에도 항상 넣음)

## 구조

```
src/
├── main.rs              옵션, 터미널 시작/종료, 이벤트 루프
├── app.rs               앱 상태 (지금 줄, 언락 알림, 틀린 단어 기록)
├── lesson.rs            한 줄 입력 처리, 오타 멈춤, 키 간격 측정
├── progress.rs          키별 통계, 언락 판정, 집중 키, 진도 데이터
├── storage.rs           파일 위치, 진도 저장/불러오기
├── corpus.rs            corpus.bin 읽기, 글자/트라이그램 빈도
├── ui.rs                화면 그리기
├── hangul.rs            한글 음절 ↔ 두벌식 키, 조합 중인 글자
├── target.rs            한 줄의 키 순서와 화면 글자 단위
├── layout/
│   ├── mod.rs           레이아웃 파일 읽기/검사
│   ├── cost.rs          손가락 배정, 자리별 비용표
│   └── plan.rs          시작 키, 언락 순서 계산 (트라이그램, 롤 판정)
└── words/
    ├── mod.rs           단어 목록, 열린 키로 거르기
    ├── generator.rs     영어 가짜 단어 생성기
    ├── korean.rs        한글 가짜 단어(음절) 생성기
    ├── line.rs          한 줄 만들기
    └── testdata/en.txt  테스트 전용 영어 단어 (실행에는 안 씀)
```

## 한글 (`--lang ko`)

- **OS 입력기는 영문으로 두고** 칩니다. 한글 조합은 프로그램이 합니다.
  한글 입력기가 켜져 있으면 화면에 안내가 나옵니다.
- **자판은 영어 레이아웃의 글자를 따라갑니다.** 표준 두벌식 대응(`q`=ㅂ, `w`=ㅈ, `e`=ㄷ, `r`=ㄱ …)을 그대로 쓰므로,
  레이아웃이 바뀌어도 `q`가 있는 자리가 ㅂ입니다.
- **Shift 글자**: `Q`=ㅃ `W`=ㅉ `E`=ㄸ `R`=ㄲ `T`=ㅆ `O`=ㅒ `P`=ㅖ. 언락 순서에 따로 들어가고, 자리 비용에 Shift 비용이 더해집니다.
- 단어는 키 순서로 바꿔서 비교합니다 (`학교` → `gkrry`). 목표 줄 아래에 친 키가 조합된 모습(`ㅎ` → `하` → `학`)이 보입니다.
- 진짜 단어가 모자랄 때만 열린 자모로 만든 음절(홑모음만, 받침은 ㄱ ㄴ ㄹ ㅁ ㅂ ㅅ ㅆ ㅇ만)로 채웁니다.
- 속도는 분당 타수(KPM, keystrokes per minute)로 표시합니다. 진도는 영어와 따로 저장됩니다 (`<레이아웃>-ko.json`).
- 계산 결과: QWERTY는 `ㅇ ㅏ ㄴ ㅣ`(d k s l)로 시작, `layouts/mine.txt`는 `ㄴ ㄱ ㅅ ㅜ ㅐ`(s r t n o)로 시작

### 한글 단어 목록

`assets/words/ko/`에 있습니다. 완성된 한글로 저장하고, 실행할 때 두벌식 키로 바꿉니다.

| 파일 | 내용 |
|---|---|
| `basic.txt` | 아주 자주 쓰는 기본 단어 |
| `short.txt`, `short2.txt` | 받침 없는 단어, 받침 하나짜리 짧은 단어 (초반 단계용) |
| `nouns.txt`, `daily.txt`, `themes.txt` | 주제별 명사, 일상 명사, 의성어·의태어 |
| `verbs.txt`, `verbs2.txt`, `adjectives.txt` | 동사, 형용사, 부사와 활용형 |
| `subtitles/top.txt` | 영화 자막 빈도순 상위 단어 약 9,600개 (`그래`, `있어`, `학교에서` 같은 실제 말투) |

합치면 중복 없이 약 1만 1천 개입니다.

`subtitles/top.txt`는 [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (Hermit Dave, OpenSubtitles 2018)의
한국어 목록 상위 1만 개에서 가져왔고, **CC BY-SA 4.0** 라이선스를 따릅니다 (출처 표시, 같은 조건으로 배포).
`scripts/import_ko_subtitles.py`로 다시 만들 수 있고, 한글만 남기고 욕설·성인 단어·흔한 외국 이름을 뺍니다.
자막 특성상 영화 속 인물 이름이 일부 남아 있을 수 있습니다.
